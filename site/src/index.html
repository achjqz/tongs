tongs stores keys in the macOS Keychain. An agent refers to a key by name, you approve with Touch ID, and the value is passed to the command as an environment variable. If the command prints the value, it is masked before the agent reads the output. tongs 把 key 存在 macOS 钥匙串里。agent 通过名字引用 key，你用 Touch ID 批准，值以环境变量的形式传给命令。如果命令把值打印出来，它会在 agent 读到输出之前被遮掉。

How it works 工作方式

Above the line: what the agent sees线上：agent 看得到的 Below the line: what happens to the value线下：值经过的地方

Store存入

$ tongs request STRIPE_SECRET_KEY
stored shop/STRIPE_SECRET_KEY (project项目 shop, 107 chars)

You paste the key into a panel that shows which agent is asking and why. It goes to the Keychain. If it is still on your clipboard, it is cleared. 你在面板里粘贴 key，面板上写明是哪个 agent 在要、用来做什么。key 存进钥匙串。如果剪贴板里还是这个 key，会被清空。

Approve批准

$ tongs run STRIPE_SECRET_KEY -- npm run deploy
tongs: waiting for Touch ID

macOS asks for Touch ID the first time. The approval lasts 12 hours and applies to that agent, project and key. tongs revoke ends it early. 第一次使用时 macOS 会要求 Touch ID。批准有效 12 小时，只对这个 agent、项目和 key 生效。tongs revoke 可以提前撤销。

Inject注入

POST /v1/payment_links
200 OK  plink_EXAMPLE

The value is set as an environment variable for that one command, and nothing else gets it. 值只作为环境变量传给这一条命令，其他程序拿不到。

Filter过滤

Authorization: Bearer ‹redacted:STRIPE_SECRET_KEY›

stdout and stderr are filtered as they stream. It matches the raw value and its URL-encoded and Base64 forms, including inside a Basic auth header. stdout 和 stderr 会被实时过滤，能匹配原值、URL 编码和 Base64 形式，Basic auth 请求头里的也能匹配。

Direct access is blocked拦截直接访问

macOS asks for a password when another program reads a Keychain item, but not when it deletes or overwrites one. A hook stops agents calling security on the Keychain. 其他程序读取钥匙串条目时 macOS 会要密码，但删除或覆盖时不会。所以 hook 不让 agent 直接用 security 操作钥匙串。

Keys per project按项目区分 key

A key is global or belongs to a git project. tongs run NAME uses the project's key first, then the global one. Worktrees count as their main repository. key 可以是全局的，也可以属于某个 git 项目。tongs run NAME 优先用项目的 key，没有再用全局的。worktree 算作它的主仓库。

No background process没有后台进程

There is no daemon or menu bar app. Each prompt is opened by the command that needs it. tongs log records each use, without values. 没有常驻服务，也没有菜单栏图标。弹窗由需要它的命令打开。tongs log 记录每次使用，不含值。

Why not paste the key into the chat 为什么不直接把 key 贴进对话

Claude Code and Codex save each session to disk and send it back to the model on every turn. A key that is pasted into the chat, or printed by a command, stays in that history. Claude Code 和 Codex 会把每次会话存到磁盘，并在每一轮重新发给模型。贴进对话的 key，或者被命令打印出来的 key，都会留在这份记录里。

Try the output filter 试试输出过滤

These are the matching rules from the CLI, running in your browser. Nothing is sent anywhere, but use a made-up value anyway. 这是 CLI 的匹配规则，在你的浏览器里运行，不会发送任何内容。不过还是请填一个编造的值。

Commands 命令

tongs lsList the keys usable in this project. Shows names and descriptions, never values.列出当前项目能用的 key，只显示名字和说明，不显示值。
tongs run NAME -- CMDRun a command with the key in its environment and filter its output.运行命令，把 key 放进它的环境变量，并过滤输出。
tongs request NAMEAsk the user for a key in a panel. Takes --why, --url and --global.弹出面板向用户要 key，可以加 --why、--url、--global。
tongs add NAMEStore a key yourself from a hidden prompt or stdin. Replacing a key takes Touch ID.自己录入 key，隐藏输入或从 stdin 读取。替换已有的 key 需要 Touch ID。
tongs rm NAMEDelete a key. Takes Touch ID.删除 key，需要 Touch ID。
tongs grants, tongs revokeShow and end active approvals.查看和撤销当前的授权。
tongs logShow who used which key, in which project, for which command.查看谁在哪个项目、为哪条命令用了哪个 key。
tongs doctorCheck Keychain, Touch ID and panel access from the current context.检查当前环境能否访问钥匙串、Touch ID 和面板。
tongs setup claude, codexInstall the hook and agent instructions. Prints the changes unless you add --apply; --remove undoes them.安装 hook 和给 agent 的说明。不加 --apply 只打印改动，--remove 可以撤销。

What it doesn't protect against 它防不了什么

tongs is meant to stop a well-behaved agent from leaking a key by accident. It can't contain an agent that is trying to steal one. tongs 的目的是防止正常工作的 agent 意外泄露 key。如果 agent 存心要偷，它拦不住。

Full threat model in SECURITY.md完整的威胁模型见 SECURITY.md

  • A command that changes the value before printing it, or writes it to a file, isn't filtered. 命令把值变换后再打印，或者写进文件，都不会被过滤。
  • For 12 hours after you approve, other commands in that project can use the key without asking. 批准后的 12 小时内，同一项目的其他命令可以直接使用这个 key，不会再询问。
  • Agent sandboxes block the Keychain, so tongs run runs its command outside the sandbox. The rules installed for Codex ask you before each run. agent 的沙箱会挡住钥匙串，所以 tongs run 要在沙箱外执行命令。给 Codex 装的规则会在每次运行前询问你。
  • The hook only checks shell commands. A script written to disk first, or a compiled program, gets past it. hook 只检查 shell 命令。先写到磁盘的脚本或编译好的程序可以绕过它。
  • Malware already running under your account can read the clipboard while you paste. 已经在你账户下运行的恶意软件，可以在你粘贴时读取剪贴板。

Questions 常见问题

How do I keep API keys out of Claude Code or Codex?怎么不让 Claude Code 或 Codex 看到 API key？

Store the key with tongs and let the agent use it by name. tongs run gives the value to one command as an environment variable and masks it in the output, so it stays out of the conversation. See what this doesn't protect against.用 tongs 存 key，让 agent 通过名字使用。tongs run 把值作为环境变量传给一条命令，并在输出里遮掉，所以值不会进入对话。它的局限见它防不了什么。

Can a coding agent read my .env file?编程 agent 能读到 .env 文件吗？

An agent that can read your project can read a .env file, and whatever it reads goes into the session. tongs keeps values in the macOS Keychain, so there is no plaintext file in the project.能读项目文件的 agent 就能读 .env，读到的内容都会进入会话。tongs 把值存在 macOS 钥匙串里，项目里没有明文文件。

How is this different from the 1Password CLI?它和 1Password CLI 有什么区别？

op run also passes secrets as environment variables and masks them in output, and it is a good fit if you already use 1Password. tongs is free and needs no account. It adds a panel an agent can open to ask for a key, approvals per agent and project, and a hook that blocks direct Keychain access.op run 同样用环境变量传递密钥，并在输出里遮掉，如果你已经在用 1Password，它很合适。tongs 免费，不需要账户。它多了 agent 可以打开的请求面板、按 agent 和项目区分的批准，以及拦截直接访问钥匙串的 hook。

Which agents does it work with?支持哪些 agent？

tongs setup supports Claude Code and Codex. Other agents can follow the commands in /llms.txt, but no hook is installed for them.tongs setup 支持 Claude Code 和 Codex。其他 agent 可以照 /llms.txt 使用这些命令，但不会装 hook。

Does it send my keys anywhere?它会把 key 发到别的地方吗？

tongs makes no network requests. A value goes only to the command you run with it, and that command can send it wherever it normally would.tongs 本身不发任何网络请求。值只会交给你用它运行的命令，这条命令会把它发到哪里，就和平时一样。

Does it work without Touch ID, or on Linux and Windows?没有 Touch ID 能用吗？支持 Linux 和 Windows 吗？

A Mac without Touch ID asks for your login password instead. tongs runs only on macOS 15 or later, because it depends on the Keychain.没有 Touch ID 的 Mac 会改为询问登录密码。tongs 只支持 macOS 15 及以上，因为它依赖钥匙串。

Install it yourself 自己安装

  • Releases aren't notarized yet. macOS runs the binary installed with brew or curl. A file downloaded in a browser is blocked until you run xattr -d com.apple.quarantine tongs. 发布版本还没有经过公证。用 brew 或 curl 安装的可以直接运行；用浏览器下载的文件会被拦截，需要先执行 xattr -d com.apple.quarantine tongs。
  • After each upgrade the Keychain asks for your login password once per key, because the signature changes. Choose Always Allow. 每次升级后签名都会变，钥匙串会对每个 key 问一次登录密码，选“始终允许”就行。
