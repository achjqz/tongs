Secrets for coding agents, on macOS 给编程 agent 用的密钥工具，macOS 版

Agents use your keys.They never see them. agent 用你的密钥，但永远看不到。

tongs keeps API keys in the macOS Keychain. Your agent asks for them by name, you approve with Touch ID, and the value goes straight into the command it was meant for. It stays out of the transcript. tongs 把 API key 放在 macOS 钥匙串里。agent 按名字使用，你用 Touch ID 批准，值直接进入需要它的命令，不会留在对话记录里。

A transcript never forgets. 对话记录不会忘记。

Everything an agent reads is saved to disk and sent back to the model on every turn. A key that lands there can't be taken back out. agent 读到的所有内容都会存到磁盘，并在每一轮重新发给模型。key 一旦进去，就再也拿不出来了。

How a key gets used 一个 key 是怎么被用的

The agent asks. You paste.agent 开口，你来粘贴。

tongs request opens a native panel that says who is asking and why. You paste the key there, and your clipboard is cleared afterwards. The agent only learns that it was stored. tongs request 会弹出原生面板，写明是谁在要、用来做什么。你在面板里粘贴，之后剪贴板会被清空。agent 只知道“已存好”。

A key belongs to one git project or to all of them. Worktrees count as their main repository, so an agent in a worktree finds the same keys. key 可以只属于某个 git 项目，也可以全局共用。worktree 归到主仓库，所以在 worktree 里干活的 agent 能找到同一套 key。

First use takes your finger.第一次使用，要你按指纹。

Approval is per agent, per project and per key, and lasts 12 hours. tongs revoke ends it early, and tongs log shows every use with its command, without values. 授权按 agent、项目、key 分别计算，有效期 12 小时。tongs revoke 可以提前撤销，tongs log 记录每次使用和对应的命令，不含值。

The value goes in and stays there.值进得去，出不来。

tongs run puts the value in the environment of that one command and scrubs its output as it streams, including a value split across two reads. tongs run 只把值放进这一条命令的环境变量，并在输出流过时实时打码，值被拆在两次读取之间也能抓到。

The side doors are shut.旁路也堵上了。

macOS only protects Keychain reads. Deleting or overwriting an item needs no prompt, so a hook for Claude Code and Codex stops agents from calling security directly. It parses the shell command, so a note that merely mentions one passes. macOS 只保护钥匙串的读取，删除和覆盖都不会弹窗。所以 tongs 给 Claude Code 和 Codex 装了 hook，不让 agent 直接调用 security。它会解析 shell 命令，文字里只是提到命令不会被误拦。

Try the scrubber. 试试打码。

This runs the same matching rules as the CLI, here in your browser. Nothing leaves this page, but use a made-up value anyway. 这里用的是和 CLI 相同的匹配规则，就在你的浏览器里运行，不会发送任何内容。不过还是请填一个编造的值。

Where it stops 它管不到的地方

tongs prevents accidents by an agent you already trust. It won't contain an agent that sets out to steal your keys. tongs 防的是你本来就信任的 agent 不小心泄露。一个存心要偷 key 的 agent，它拦不住。

Read the threat model阅读完整威胁模型 →
  • Transformed output变换后再输出 A command that reverses the value or writes it to a file gets past the scrubber. 命令把值倒过来再打印，或者写进文件，都能绕过打码。
  • The 12-hour window12 小时授权期 Once approved, other commands in that project can use the key without asking again. 批准之后，同一项目里的其他命令也能直接用这个 key，不会再问。
  • Agent sandboxesagent 沙箱 Sandboxes block the Keychain, so tongs run runs outside them. Codex shows you each command first. 沙箱会挡住钥匙串，所以 tongs run 在沙箱外运行。Codex 会先把每条命令给你看。
  • Scripts and helpers脚本和编译程序 The guard reads commands. A script written to disk first, or a compiled helper, gets past it. 守卫只看命令。先写到磁盘的脚本、编译好的程序都能绕过它。
  • Malware on your Mac你电脑上的恶意软件 Code already running as you can read the clipboard while you paste. 已经以你的身份运行的程序，可以在你粘贴时读取剪贴板。

Install 安装

macOS 15 or later, with Xcode 26 or a Swift 6.2 toolchain to build. 需要 macOS 15 及以上，构建需要 Xcode 26 或 Swift 6.2 工具链。

  • Leave out --apply to see every change first. Add --remove to undo them; your keys stay put. 不加 --apply 只显示将要做的改动。加 --remove 可以撤销，已存的 key 不受影响。
  • Each rebuild gets a new signature, so the Keychain asks for your login password once per key. Choose Always Allow. 每次构建签名都会变，钥匙串会对每个 key 问一次登录密码，选“始终允许”就行。

The colours here are temper colours. Polished steel turns straw at about 230 °C, bronze at 260 °C, purple at 280 °C and blue at 300 °C. Tongs are how you hold it while it does. 这里的颜色是钢的回火色。抛光的钢在约 230 °C 变成麦秆色，260 °C 变成青铜色，280 °C 变成紫色，300 °C 变成蓝色。这时候要拿它，就得用钳子。
