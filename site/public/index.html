Let coding agents use your API keys without seeing them 让编程 agent 使用你的 API key，而看不到它的值

tongs stores keys in the macOS Keychain. An agent refers to a key by name, you approve with Touch ID, and the value is passed to the command as an environment variable. If the command prints the value, it is masked before the agent reads the output. tongs 把 key 存在 macOS 钥匙串里。agent 通过名字引用 key，你用 Touch ID 批准，值以环境变量的形式传给命令。如果命令把值打印出来，它会在 agent 读到输出之前被遮掉。

Why not paste the key into the chat 为什么不直接把 key 贴进对话

Claude Code and Codex save each session to disk and send it back to the model on every turn. A key that is pasted into the chat, or printed by a command, stays in that history. Here is the same task both ways. Claude Code 和 Codex 会把每次会话存到磁盘，并在每一轮重新发给模型。贴进对话的 key，或者被命令打印出来的 key，都会留在这份记录里。下面是同一件事的两种做法。

How it works 工作方式

Storing a key存 key

tongs request opens a panel showing which agent is asking and why. You paste the key there. The agent gets back the name, the length and the kind of key. If the key is still on your clipboard, it is cleared. tongs request 会打开一个面板，写明是哪个 agent 在要、用来做什么，你在面板里粘贴。agent 拿到的只有名字、长度和 key 的类型。如果剪贴板里还是这个 key，会被清空。

Approving use批准使用

The first time an agent uses a key in a project, macOS asks for Touch ID. The approval lasts 12 hours and applies to that agent, project and key. tongs revoke ends it early. agent 第一次在某个项目里用某个 key 时，macOS 会要求 Touch ID。批准有效 12 小时，只对这个 agent、项目和 key 生效。tongs revoke 可以提前撤销。

Running a command运行命令

tongs run sets the environment variable for that command only and filters stdout and stderr as they stream. It matches the raw value, its URL-encoded form and its Base64 form, including inside a Basic auth header. tongs run 只给这一条命令设置环境变量，并实时过滤 stdout 和 stderr。它能匹配原值、URL 编码和 Base64 形式，Basic auth 请求头里的也能匹配。

Blocking direct access拦截直接访问

macOS asks for a password when another program reads a Keychain item, but not when it deletes or overwrites one. A PreToolUse hook for Claude Code and Codex blocks agents from calling security on the Keychain directly. 其他程序读取钥匙串条目时 macOS 会要密码，但删除或覆盖时不会。所以 tongs 给 Claude Code 和 Codex 装了 PreToolUse hook，不让 agent 直接用 security 操作钥匙串。

Keys per project按项目区分 key

A key is either global or belongs to a git project. tongs run NAME uses the project's key first and falls back to the global one. Worktrees count as their main repository. key 可以是全局的，也可以属于某个 git 项目。tongs run NAME 优先用项目的 key，没有再用全局的。worktree 算作它的主仓库。

No background process没有后台进程

There is no daemon or menu bar app. Each prompt is opened by the command that needs it and closes with it. tongs log keeps a record of each use, without values. 没有常驻服务，也没有菜单栏图标。弹窗由需要它的命令打开，命令结束就关闭。tongs log 记录每次使用，不含值。

Commands 命令

tongs lsList the keys usable in this project. Shows names and descriptions, never values.列出当前项目能用的 key，只显示名字和说明，不显示值。
tongs run NAME -- CMDRun a command with the key in its environment and filter its output.运行命令，把 key 放进它的环境变量，并过滤输出。
tongs request NAMEAsk the user for a key in a panel. Takes --why, --url and --global.弹出面板向用户要 key，可以加 --why、--url、--global。
tongs add NAMEStore a key yourself from a hidden prompt or stdin. Replacing a key takes Touch ID.自己录入 key，隐藏输入或从 stdin 读取。替换已有的 key 需要 Touch ID。
tongs rm NAMEDelete a key. Takes Touch ID.删除 key，需要 Touch ID。
tongs grants, tongs revokeShow and end active approvals.查看和撤销当前的授权。
tongs logShow who used which key, in which project, for which command.查看谁在哪个项目、为哪条命令用了哪个 key。
tongs setup claude, codexInstall the hook and agent instructions. Prints the changes unless you add --apply; --remove undoes them.安装 hook 和给 agent 的说明。不加 --apply 只打印改动，--remove 可以撤销。

What it doesn't protect against 它防不了什么

tongs is meant to stop a well-behaved agent from leaking a key by accident. It can't contain an agent that is trying to steal one. tongs 的目的是防止正常工作的 agent 意外泄露 key。如果 agent 存心要偷，它拦不住。

  • A command that changes the value before printing it, or writes it to a file, isn't filtered. 命令把值变换后再打印，或者写进文件，都不会被过滤。
  • For 12 hours after you approve, other commands in that project can use the key without asking. 批准后的 12 小时内，同一项目的其他命令可以直接使用这个 key，不会再询问。
  • Agent sandboxes block the Keychain, so tongs run runs its command outside the sandbox. The rules installed for Codex ask you before each run. agent 的沙箱会挡住钥匙串，所以 tongs run 要在沙箱外执行命令。给 Codex 装的规则会在每次运行前询问你。
  • The hook only checks shell commands. A script written to disk first, or a compiled program, gets past it. hook 只检查 shell 命令。先写到磁盘的脚本或编译好的程序可以绕过它。
  • Malware already running under your account can read the clipboard while you paste. 已经在你账户下运行的恶意软件，可以在你粘贴时读取剪贴板。

Install 安装

  • Releases aren't notarized yet. macOS runs the binary installed with brew or curl. A file downloaded in a browser is blocked until you run xattr -d com.apple.quarantine tongs. 发布版本还没有经过公证。用 brew 或 curl 安装的可以直接运行；用浏览器下载的文件会被拦截，需要先执行 xattr -d com.apple.quarantine tongs。
  • After each upgrade the Keychain asks for your login password once per key, because the signature changes. Choose Always Allow. 每次升级后签名都会变，钥匙串会对每个 key 问一次登录密码，选“始终允许”就行。
